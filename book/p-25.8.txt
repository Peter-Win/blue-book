#P-25.8
en: Parent components in decreasing order of seniority (partial lists) 
ru: &(Parent component|*) в порядке убывания старшинства (частичные списки)

en: In this subsection rings and ring systems are listed in decreasing order of seniority for selection as a parent component. 
The first list contains heterocyclic parent components, the second hydrocarbon parent components. 
ru: В этом подразделе кольца и кольцевые системы перечислены в порядке убывания старшинства для выбора в качестве 
&(parent component|ro).
Первый список содержит гетероциклические &(parent component|vi*), второй — углеводородные &(parent component|vi*).

#P-25.8.1
en: Partial list of heterocyclic parent components in decreasing order of seniority 
ru: Частичный список гетероциклических &(parent component|ro*) в порядке убывания старшинства

en: The following list contains parent heterocycles arranged in decreasing order of seniority for selection as the parent 
component for fusion names. Ring systems containing Hg as given in ref. 4 are not included in these recommendations. 
ru: Следующий список содержит &(parent heterocycle|vi*), расположенные в порядке убывания старшинства для выбора в 
качестве &(parent component|ro) для &(fusion name|ro*). 
Кольцевые системы, содержащие Hg, как указано в ссылке 4, не включены в эти рекомендации.

en: The parent heterocycles are arranged by ring analysis, i.e., in decreasing order of number rings, ring size, and in 
accordance with the priority given to heteroatoms, <%atoms%>. 
ru: &(Parent heterocycle|*) расположены по анализу колец, т. е. в порядке убывания числа колец, размера кольца и в 
соответствии с приоритетом, отданным гетероатомам <%atoms%>.
%atoms: N, O, S, Se
